# 📘 6-Month SDE 1 Interview Preparation Roadmap

This roadmap helps you prepare for SDE 1 roles in **India and globally** with a structured 6-month plan. It includes weekly goals, resource links, and project ideas — optimized for **15–20 hrs/week** effort.

---

## 🧭 Overview

| 📆 Duration  | 🧠 Focus Area                                     | Outcome                                            |
|--------------|--------------------------------------------------|----------------------------------------------------|
| Month 1–2     | DSA Basics + First Project                       | Strong problem-solving foundation                  |
| Month 3–4     | Advanced DSA + System Design Intro               | Fluency with coding and scalable system thinking   |
| Month 5       | Projects + Mock Interviews                       | Deployable projects + Interview readiness          |
| Month 6       | Job Applications + Final Interview Practice      | Resume polish, mock rounds, and job submissions    |

---

## 🔰 Phase 1: DSA Foundation + First Project (Month 1–2)

### ✅ Topics
- Arrays, Strings, Linked Lists, Hash Tables
- Stacks, Queues, Sliding Window, Two Pointer
- Recursion, Binary Search

### 📚 Resources
- [LeetCode Easy–Medium](https://leetcode.com/)
- [NeetCode 150](https://neetcode.io/roadmap)
- [GFG DSA Sheet](https://www.geeksforgeeks.org/sde-sheet/)

### 💡 Project Ideas
- 📝 **Blog App** (React + Node.js + MongoDB / Spring Boot + React)
- ✅ **Task Manager App** (JavaScript + Express or Java + Spring Boot)

---

## 🧠 Phase 2: Advanced DSA + System Design Intro (Month 3–4)

### ✅ Topics
- Trees, Graphs, Backtracking
- Dynamic Programming (Knapsack, LIS, etc.)
- Merge Sort, Quick Sort, Heap, Trie

### 📚 Resources
- [LeetCode Medium–Hard](https://leetcode.com/)
- [Tech Interview Handbook](https://www.techinterviewhandbook.org/)
- [AlgoExpert (optional)](https://www.algoexpert.io/)

### ⚙️ System Design Basics
- Concepts: Load balancing, Caching, Sharding
- REST APIs, Database Schema Design
- [System Design Primer](https://github.com/donnemartin/system-design-primer)

### 💡 Project Ideas
- 🛒 **Mini e-Commerce Site** (MERN / Spring Boot + Thymeleaf)
- 💬 **Real-Time Chat App** (Node.js + React + Redis/Firebase)

---

## 🎯 Phase 3: Mock Interviews + Project Polish (Month 5)

### 🔍 Mock Practice
- [Pramp](https://www.pramp.com/)
- [interviewing.io](https://www.interviewing.io/)
- Peer sessions or college seniors

### 🛠 Project Enhancement
- Add a clean `README.md` with live demo links
- Deploy Frontend: Vercel / Netlify
- Deploy Backend: Render / Heroku

---

## 💼 Phase 4: Final Tuning + Job Hunt (Month 6)

### 🎯 Action Items
- Apply to **50+ companies**
- Final round of mock interviews

### 📄 Resume Resources
- [Enhancv](https://enhancv.com/)
- [GeeksforGeeks Resume Template](https://www.geeksforgeeks.org/resume-building-for-freshers/)

### 🧠 Behavioral Prep
- Use **STAR Method**: Situation, Task, Action, Result
- Sample Questions:
  - "Tell me about a time you solved a hard bug"
  - "Explain your project to a 10-year-old"
- 📘 *Cracking the Coding Interview* by Gayle Laakmann McDowell
